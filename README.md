# Banking Dashboard – Power BI

## Overview
An interactive Banking Dashboard developed using Microsoft Power BI to analyze banking data and generate meaningful insights. The dashboard helps explore customer information, loan performance, and key banking metrics through interactive visualizations.

## Project Files
- `Banking dash project.pbix` – Power BI dashboard file.
- `Loan_Fact.xlsx` – Excel dataset used for analysis.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Visualization

## Key Features
- Interactive dashboard and visualizations.
- Key Performance Indicators (KPIs).
- Dynamic filters and slicers.
- Loan performance analysis.
- DAX measures for calculating important banking metrics.
- Data-driven insights for better decision-making.

## Project Objectives
- Analyze banking and loan-related data.
- Identify trends and patterns.
- Track important banking metrics.
- Develop interactive dashboards for data analysis.

## How to Use
1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. If required, connect the Excel dataset.
4. Refresh the data.
5. Explore the dashboard using filters and slicers.
